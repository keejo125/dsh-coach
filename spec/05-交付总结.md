## 二、功能实现

主对话页新增「上下文」Tab（最右，order 100），三栏同屏（1 : 1.2 : 1）展示：

- **输入栏**：用户主动输入（提示词 + 附件）时间线卡片；系统自动注入内容折叠区，文件类注入以目录树展示并带「系统注入」徽标，与用户主动提供明确区分；长文可开抽屉看全文。
- **参考栏**：目录树展示会话中查看过的文件，每文件标注查看次数（×N，重复读取累计计入），点击抽屉查看正文。
- **输出栏**：文字输出卡片（摘要 + 查看全文）与文件输出目录树（新建/更新标记），点击抽屉查看正文，正文按扩展名做基础高亮。
- **多 Agent 标识**：每条输入/参考/输出标注来源 Agent，支持按 Agent 筛选（真实 12 Agent 会话实测通过）。

### v1.1 改版（输出改为最终产物、输入按 Agent 分组）

- **输出栏只给最终产物**：每个 Agent 只呈现其最终答复（该 Agent 时间序最后一段非空文本；空文本不产段，零文本 Agent 不占文字区）。逐轮与逐步骤的中间过程输出**默认不显示**，界面提供「显示过程输出」开关（默认关闭，数据保留供切换），过程段正文以 320 字节预览呈现且不计入预算。真实会话实测：输出由 **280 段 → 12 条最终答复**。
- **输入栏按 Agent 分组**：每个 Agent 一块（主 Agent 最前），块内汇总该 Agent 的输入（提示词、注入文档、它收到的委派指令）。**委派指令归子 Agent**（谁收到算谁的）；子会话降级或缺失时，从父会话委派记录兜底提取并标注为临时条目。
- **「查看全文」改为按段标识取**：每段带稳定 id（会话:序号），端点按 id 取全文，**根治静默错位**；同时删除原先"两个数组必须配对排序"的脆弱耦合。
- **截断提示两类分派**：全局类（条目超限、参考超限、子会话降级）只在「全部 Agent」视图显示；可见类（单条 4KB 截断）按筛选后可见集合重算，杜绝同屏数值矛盾。
- **标签消歧**：同名子 Agent 自动追加会话短码（仅在冲突时），短码取能区分开的最短前缀。

## 四、过程质量问题处置

1. **输出全文下标错位**（高风险，QA 发现）：多 Agent 交错输出时排序未同步全文数组 → 点「查看全文」返回另一段。已修并补交错时间线回归用例。
2. **输出文件树缺 Agent 归属**（工程师复查发现）：QA 只修了注入树，输出树同类缺陷会致筛选后整棵清空。已一并修（真实数据反证：修复后输出栏 18 个文件，未修则为 0）。
3. **macOS realpath 陷阱**：工作区根未归一化会导致工作区内所有读取被误判 403。已修。
4. **实现级异常被吞成 404**：故障静默。已按错误家族甄别，收敛为 `CTX_INTERNAL` 且信息脱敏。
5. **host 侧私自缓存**（与"即时聚合、无状态"设计定稿相悖）：已删除。
6. **注入路径提取误报**（真实环境暴露）：注入文件树混入 `policy:`、`sandbox`、`Bash/formatters`、npm 包名、目录等非文件条目，与"宁缺勿错"口径不符。已收紧为两条规则（剥离 `file:line` 后拒含冒号 token；末段须为文件名形态，并以已知无扩展名文件名白名单补回），真实会话复跑后注入树 **17 → 11**，剔除 6 条误报、真阳性 11 条全部保留。
